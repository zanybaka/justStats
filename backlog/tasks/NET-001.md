Task Context
New Modules/Net (first module after Disk; same Kit/Modules shape per TECHSPEC §1). Per-interface byte counters via sysctl mib [CTL_NET, PF_ROUTE, 0, 0, NET_RT_IFLIST2] parsing RTM_IFINFO2 (if_msghdr2) -> ifi_ibytes/ifi_obytes; mechanics verified in exelban/stats Modules/Net/readers.swift (MIT, read 2026-11-21). Rates are deltas vs previous totals, clamped >=0; implausible one-shot jumps (link rate from ifi_baudrate x interval x 1.5, else a fixed cap) are zeroed, as in Stats. Physical vs virtual interfaces split by name-prefix filter (utun, ipsec, ppp, tun, tap, gif, stf, wg): virtual interfaces keep their own counters and rows, never merged into a physical one. Since-boot totals come straight from the monotonic counters (single read, no accumulation work); reset stores an offset. Ring buffer of 180 samples feeds the chart. Pure unit-testable core (delta/clamp/cutoff/filter/totals/reset) with an injectable counter source; the sysctl call itself a thin layer. Sampler is created idle and started/stopped by the popover (NET-002): owner decisions 2026-11-21 — no menu bar item, sampling only while the popover is open, so nothing network-related runs at launch or at idle. Record in techspec: the net module keeps the ADR-002 two-tier shape with sampler-on-open as its only live tier.
